### Observation 1: Preserve the primary device workflow during a redesign

**Status:** OPEN
**Date:** 2026-09-08
**Session context:** Salon menu redesign
**Skill:** sites-building
**Type:** open-source
**Phase/Area:** Establishing the visual direction

**Issue:** An editorial homepage obscured a deliberate mobile quick-choice grid. The user clarified that immediate menu access was the primary purpose.

**Suggested improvement:** Before replacing a homepage composition, identify its primary device and the task its existing layout optimizes. Preserve that task while improving visual quality.

**Principle:** A professional redesign improves the speed and clarity of the primary user task before adding visual storytelling.

### Observation 2: Reject default AI spa sage-and-champagne palettes

**Status:** OPEN
**Date:** 2026-09-08
**Session context:** User rejected sage green / champagne gold salon palette as horrid
**Skill:** sites-building / frontend design preferences
**Type:** open-source
**Phase/Area:** Color system defaults

**Issue:** A soft sage primary with champagne accent and warm cream canvas was shipped as a "spa" refresh. The user rejected it immediately as looking bad. That combination matches a common AI-default salon look.

**Suggested improvement:** Prefer distinctive cool mineral or beauty-industry directions over sage+gold+cream. When redesigning brand colors, avoid the cream-and-terracotta/champagne cluster and muddy greens unless the brand already owns them.

**Principle:** Default "spa" palettes (sage green + champagne gold + warm cream) read as generic AI design — choose a clearer, cooler, more distinctive system unless the brand already uses those hues.
