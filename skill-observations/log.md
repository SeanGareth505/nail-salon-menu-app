### Observation 1: Preserve the primary device workflow during a redesign

**Status:** OPEN
**Date:** 2026-09-08
**Session context:** Salon menu redesign
**Skill:** sites-building
**Type:** open-source
**Phase/Area:** Establishing the visual direction

**Issue:** An editorial homepage obscured a deliberate mobile quick-choice grid. The user clarified that immediate menu access was the primary purpose.

**Suggested improvement:** Before replacing a homepage composition, identify its primary device and the task its existing layout optimizes. Preserve that task while improving visual quality.

**Principle:** A professional redesign improves the speed and clarity of the primary user task before adding visual storytelling.
